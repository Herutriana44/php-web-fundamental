Berikut adalah alur pembelajaran fundamental **MySQL** menggunakan antarmuka **phpMyAdmin**. Di sini kita akan langsung berfokus pada **SQL Query** (perintah teks) yang dieksekusi di dalam tab **"SQL"** pada phpMyAdmin. Ini adalah dasar dari operasi **CRUD** (Create, Read, Update, Delete) yang akan sering Anda panggil melalui kode PHP. ## 1. Mengenal Tipe Data Penting di MySQL Sebelum membuat tabel, Anda harus menentukan tipe data untuk setiap kolom (*field*). Berikut 4 tipe data yang paling sering digunakan: * **INT**: Untuk angka bulat (contoh: ID, umur, jumlah stok). * **VARCHAR(panjang)**: Untuk teks/string dengan batasan panjang variabel (contoh: nama, email, password). * **TEXT**: Untuk teks panjang tanpa batasan ketat (contoh: isi artikel, alamat lengkap). * **DATE** / **DATETIME**: Untuk menyimpan tanggal dan waktu. ## 2. Membuat Tabel (CREATE TABLE) Perintah ini digunakan untuk membuat struktur tabel baru. Kita juga menentukan **PRIMARY KEY** (identitas unik tiap baris) dan **AUTO_INCREMENT** (angka ID yang otomatis bertambah). ```sql CREATE TABLE mahasiswa ( id INT NOT NULL AUTO_INCREMENT, nama VARCHAR(100) NOT NULL, prodi VARCHAR(50) NOT NULL, ipk FLOAT, tanggal_daftar DATE, PRIMARY KEY (id) ); ``` > **Info phpMyAdmin**: Anda bisa masuk ke sebuah database, klik tab **SQL**, tempel kode di atas, lalu klik tombol **Go**. > ## 3. Memasukkan Data (INSERT INTO) Digunakan untuk menambahkan baris data baru ke dalam tabel yang sudah dibuat. ```sql -- Memasukkan satu data INSERT INTO mahasiswa (nama, prodi, ipk, tanggal_daftar) VALUES ('Rian Hidayat', 'Informatics', 3.75, '2026-06-10'); -- Memasukkan beberapa data sekaligus INSERT INTO mahasiswa (nama, prodi, ipk, tanggal_daftar) VALUES ('Siti Aminah', 'Informatics', 3.89, '2026-06-11'), ('Budi Santoso', 'Sistem Informasi', 3.40, '2026-06-11'); ``` ## 4. Membaca & Menampilkan Data (SELECT) Perintah yang paling sering digunakan untuk mengambil data dari database. ```sql -- 1. Mengambil semua kolom dan semua baris data SELECT * FROM mahasiswa; -- 2. Hanya mengambil kolom tertentu saja (lebih ringan dan efisien) SELECT nama, prodi FROM mahasiswa; ``` ## 5. Menyaring Data (WHERE) Digunakan bersama perintah SELECT, UPDATE, atau DELETE untuk membatasi baris mana saja yang akan diproses berdasarkan kondisi tertentu. ```sql -- Mengambil mahasiswa yang mengambil prodi Informatics SELECT * FROM mahasiswa WHERE prodi = 'Informatics'; -- Mengambil mahasiswa dengan IPK di atas 3.50 SELECT nama, ipk FROM mahasiswa WHERE ipk > 3.50; -- Menggunakan kombinasi AND (kedua kondisi harus terpenuhi) SELECT * FROM mahasiswa WHERE prodi = 'Informatics' AND ipk > 3.80; ``` ## 6. Mengubah Data (UPDATE) Digunakan untuk memperbarui data yang sudah ada di tabel. > ⚠️ **PENTING**: Selalu gunakan klausa WHERE. Jika Anda lupa menuliskan WHERE, **semua baris data** di tabel tersebut akan berubah! > ```sql -- Mengubah IPK milik mahasiswa yang memiliki id = 1 UPDATE mahasiswa SET ipk = 3.80 WHERE id = 1; ``` ## 7. Menghapus Data (DELETE) Digunakan untuk menghapus baris data dari tabel. > ⚠️ **PENTING**: Sama seperti UPDATE, selalu gunakan klausa WHERE agar tidak menghapus seluruh isi tabel secara tidak sengaja. > ```sql -- Menghapus baris mahasiswa yang memiliki id = 3 DELETE FROM mahasiswa WHERE id = 3; ``` ## 8. Mengurutkan Hasil (ORDER BY) Digunakan untuk mengurutkan data yang ditampilkan berdasarkan kolom tertentu. * **ASC**: Mengurutkan dari terkecil ke terbesar (A-Z, 0-9). * **DESC**: Mengurutkan dari terbesar ke terkecil (Z-A, 9-0). ```sql -- Menampilkan mahasiswa dengan urutan IPK tertinggi ke terendah SELECT * FROM mahasiswa ORDER BY ipk DESC; ``` ### Integrasi ke Pembelajaran Sebelumnya: Sekarang Anda bisa melihat gambaran besarnya. Di tahap PHP sebelumnya, saat Anda menuliskan kode: ```php $query = "SELECT * FROM mahasiswa"; $statement = $pdo->prepare($query); ``` String $query tersebut diisi oleh perintah SQL Query asli yang baru saja kita pelajari ini. Server MySQL akan mengeksekusi perintah tersebut, lalu mengembalikan hasilnya ke PHP untuk diubah menjadi struktur tampilan HTML dan CSS di sisi browser.
