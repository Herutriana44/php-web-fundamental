# Bab 1: HTML Basic

HTML (HyperText Markup Language) adalah bahasa markup standar untuk membuat halaman web.

## Struktur Dasar
```html
<!DOCTYPE html>
<html>
<head>
    <title>Judul Halaman</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Ini adalah paragraf pertama saya.</p>
</body>
</html>
```
